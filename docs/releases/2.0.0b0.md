# v2.0.0b0

以 `2.0` 为基础开启新版本线，包含基于 HomeMate 5.2.6.307 逆向证据的协议重构。
此前 `0.2.6b17` 的门锁抓拍、卡片和视频功能继续保留。

- **调光灯**：统一类型 0、116 和其中虚拟 MixPad 调光器的原生亮度刻度，支持开关及亮度；HA 亮度 0 执行关闭，局部状态推送保留有效模式与亮度。
- **RF 窗帘**：明确标记为 RF 的类型 34/35 支持开、关、停。没有位置滑块，位置和关闭状态保持未知，不推测电机已到位。
- **状态与通道**：库存初始化、云刷新、SSL/LAN 推送和乐观状态共用协议单位，SSL 与 LAN 复用封包；保留型号、RF 标记等身份元数据。
- **文档与发布**：同步设备支持、架构、服务和视频指南，补齐迁移说明及完整文档索引；发布流水线支持 2.0 主版本号。

在 HACS 更新或重新下载 **v2.0.0b0**，**重启 Home Assistant 后强制刷新浏览器**。
已有配置项、实体唯一 ID、卡片和本地门锁媒体可保留，内部配置格式版本仍为 3。
RF 窗帘的自动化应使用开、关、停，不能依赖位置或关闭状态判断到位。
升级步骤与回退见 [迁移指南](../MIGRATION.md)。

本版新增协议依据静态逆向与离线测试实现，**116、虚拟 MixPad 调光及 RF 34/35 分支尚待真机验证**，
`hardware_verified` 保持 false。未扩展其他灯光、窗帘方向、空调或 IR 候选协议。
NVR 1/3 号实时播放沿用已有用户反馈，硬盘与 SD/TF 录像查询和回放仍待实机验证。
详细公式与证据见 [2.0 协议重构](../protocol-profiles-2.0.md)。

验证：Python 3.12 全量测试运行 **812 项，810 项通过、2 项因缺少 FFmpeg 跳过**。
包含新主版本的完整发布脚本模拟；新增调光/RF 分支的独立只读审查未发现阻塞缺陷。
184 个 Python 文件通过 AST 检查，两个卡片模块的 Node.js 语法检查和新增协议模块/测试的 Ruff 检查通过。
GitHub 发布流水线还会执行全量测试（含 FFmpeg）、HACS validation 与 hassfest。

本版按普通 GitHub Release / Latest 发布，`Pre-release=false`。`b0` 区分临时版本，
无需在 HACS 启用预发布；下一次临时版本为 `2.0.0b1`。
