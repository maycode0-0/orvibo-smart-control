# 2.0.0b4 摄像机视频解析 CPU 优化

此临时诊断版针对摄像机加载时 CPU 占用升高的反馈，修复协议接收进程反复用
Python 逐字节扫描视频帧边界造成的明显开销，改用底层字节查找。帧边界、参数集、
加密帧处理与输出字节保持一致，不降低分辨率、画质或帧率。

在 HACS 更新或重新下载 **v2.0.0b4** 后，**重启 Home Assistant**，再加载视频，
观察 CPU 曲线以及刷新页面时是否仍暂时无法连接。
手动安装可下载 Release 中的 `orvibo-smart-control.zip`，解压到
`<ha-config>/custom_components/orvibo_smart_control/`，整体替换旧组件后重启。

验证：Python 3.12 全量 **847 项测试通过，无跳过**，包含真实 FFmpeg 转码与
PyAV 连续解码。新增扫描边界、穷举与随机差分、参数集缓存和实际接收路径的字节
一致性回归；独立审查与随机差分验证未发现扫描结果变化。

本地合成加密 1080p HEVC（无 AUD、20 fps）300 帧解析对照：旧版消耗
**7.375 秒 CPU**，优化后约 **0.047 秒**，输出数据的哈希完全一致。
此结果仅衡量协议解析，不包含 FFmpeg 转码，不代表用户 HAOS 的整机 CPU 降幅。
用户报告的 CPU 99% 与页面断连是否改善，仍需升级后的真机验证。

本版继承 b3 的首次连接恢复、断线重试及 503 原因诊断。2.0 新增的 116、
虚拟 MixPad 调光与 RF 34/35 分支仍为 `hardware_verified=false`。

按普通 GitHub Release / Latest 发布，`Pre-release=false`；下一次临时版本为 `2.0.0b5`。
