# 2.0.0b8 MixPad 背景音乐控制

此临时诊断版在 `2.0.0b7` 基础上，为类型 `128` 的 MixPad 背景音乐主机增加
Home Assistant `media_player` 实体，保留此前的调光、窗帘、门锁和视频功能。

在 HACS 更新或重新下载 **v2.0.0b8** 后，**重启 Home Assistant**。
在集成设备选择中勾选背景音乐主机，再打开对应媒体实体或添加 HA 媒体控制卡片。
手动安装可下载本 Release 的 `orvibo-smart-control.zip`，解压到
`<ha-config>/custom_components/orvibo_smart_control/`，整体替换旧组件后重启。

- 支持播放、暂停、上一首、下一首、音量、静音和播放进度跳转。
- 显示设备返回的标题、歌手、专辑、封面、时长和播放位置。
- 登录云端后查询初始音乐状态，并解析音乐属性和 `cmd=15 statusList` 响应。
- 只为类型 `128` 创建媒体实体；类型 `114/45` 网关不会重复创建实体。

本地 117 项定向回归通过，覆盖音乐实体、命令与单位转换、属性解析、SSL 响应、
云专属能力和发布流程。Python 编译、两张内置卡片语法和 Git 差异检查通过。
完整测试、HACS validation 与 hassfest 由发布流水线在 Linux 验证，通过后才公开安装包。

音乐控制使用云端 SSL，需要默认结合模式或纯云端模式。纯 LAN 模式无法控制音乐。
暂不支持任意 URL 播放、投屏、音源选择或歌单管理。

协议来自智家 365 `5.2.6.307` APK 的 REA/JADX 静态分析；本次未在真实 HA 和 MixPad
上执行控制验证，`hardware_verified` 保持 false。更新后请重点验证每项动作是否生效，
以及 App 改变播放、音量和曲目后 HA 能否同步状态。

按普通 GitHub Release / Latest 发布，`Pre-release=false`；下一次临时版本为 `2.0.0b9`。
