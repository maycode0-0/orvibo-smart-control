# v0.2.6b16

修复页面刷新时两个 ORVIBO Lovelace 自定义卡片偶发显示 `Custom element doesn't exist` 配置错误的问题。

- **竞态恢复**：Home Assistant 会并行加载 Lovelace JavaScript 资源和仪表盘配置。两个内置卡片模块完成自定义元素注册后，现在会请求 Lovelace 重建已过早创建的卡片。
- **用户影响**：更新后保留现有卡片配置，页面刷新时无需手动删除并重新添加卡片。

Node.js 卡片语法检查通过，卡片回归测试 9 项、资源注册测试 11 项和新增刷新竞态测试 1 项通过。
完整 Python 测试、HACS validation 和 hassfest 由发布流水线执行。

本版按普通 Release / Latest 发布，bN 用于区分临时诊断版本，不标记为 Pre-release。
