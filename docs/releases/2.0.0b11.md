# 2.0.0b11 修复灯光开关误报

此临时诊断版修复 HA 把已关灯具计为开启的问题。灯光解析优先读取明确的属性开关状态，
缺少有效属性时才使用旧版开关字段。关灯后收到的非零亮度更新只修改记忆亮度，保留
已有开关状态。这覆盖普通调光调色灯、Fast Move 灯及其他使用相同解析规则的灯具。

在内置市场或 HACS 更新到 **v2.0.0b11** 后，**重启 Home Assistant**。可手动下载
`orvibo-smart-control.zip`，解压并整体替换 `<ha-config>/custom_components/orvibo_smart_control/`，
再重启。升级后，建议对照欧瑞博 App 核对开启数量，再关掉一盏灯，确认随后收到的
亮度更新不会让它重新显示为开启。

离线验证：基于 b10 的合成数据复现“4 盏亮、HA 统计 9 盏亮”及关灯后仅推送亮度
却重新显示开启；修复通过库存初始化、云端刷新、开关和亮度增量推送回归。Python 3.12
全量 **951 项通过，无跳过**，包含真实 FFmpeg 转码和 PyAV 解码。

用户报告 HA 显示 9 盏开启，现场和欧瑞博 App 均为 4 盏。对应真机原始报文尚未取得，
本版仍需升级后核对；既有协议档案的 `hardware_verified` 标记保持不变。

本版为普通 GitHub Release / Latest，`Pre-release=false`；下一次临时版本为 `2.0.0b12`。
