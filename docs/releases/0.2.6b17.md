# v0.2.6b17

猫眼抓拍在首次打开或刷新页面后，图片请求若一直 Pending / Stalled，卡片现在会超时重试，并在仍失败时显示提示，避免永久空白。

- **超时与重试**：最多同时下载 2 张图片；每次请求（含重试时重新解析地址和读取图片内容）最多等待 12 秒，失败后重新获取签名地址并自动重试一次。
- **图片复用**：最新预览、历史缩略图和大图共用已下载图片；卡片重绘无需重复下载。
- **手动恢复**：仍失败时显示“图片加载失败，请刷新抓拍重试”。右上角刷新按钮可重试挂起或失败的图片，并保留已成功加载的图片。
- **资源清理**：移除卡片、切换配置或淘汰历史图片时取消未完成请求并释放图片缓存。

验证：Python 3.12 完整测试运行 794 项，792 项通过、2 项跳过；Node.js 卡片语法检查通过。
真实无界面 Edge 浏览器验证 4 组通过，覆盖超时重试、永久挂起后的手动恢复、HTTP 404 重试上限和连接占满导致的排队。
发布流水线还会执行完整测试、HACS validation 和 hassfest。

安装：在 HACS 更新到 **v0.2.6b17**，重启 Home Assistant，再强制刷新浏览器（Windows 使用 Ctrl+F5）。现有卡片配置可继续使用。

浏览器最初进入 Stalled 的原因尚未确认；本版解决卡片缺少超时恢复机制造成的持续空白，真实 Home Assistant 环境的抓拍加载与刷新恢复仍需真机验证。
