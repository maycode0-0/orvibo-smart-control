# v2.0.0b1

修复设备选择页把已实现视频功能的摄像机和 NVR 标成“暂未支持”的问题。

- Meari 摄像机（`deviceType=14`、`camera_type=8–10`）和 NVR（`162`）显示“支持实时视频”。
- 其他 SDK 明确显示“仅支持状态信息，视频暂未支持”，不把库存状态支持误写成整台设备未支持。
- 选择页、摄像头实体注册、能力表、SDK 诊断及诊断传感器共用视频支持判定；修正始终为 false 的 `stream_supported`。

此标记表示集成已经实现相应视频路由，不表示连接成功或新增真机验证；设备控制通道和
`hardware_verified` 保持原有策略。实际播放仍需匹配 Meari XTS/p2p2 库存、鉴权及实际通道。
已有实体、设备选择及配置项可保留。

在 HACS 更新或重新下载 **v2.0.0b1** 后，**重启 Home Assistant** 并重新打开设备选择页。
本次修改在 Python 后端，单纯刷新浏览器不能加载新代码。

验证：75 项摄像头、选择页和能力回归通过；Python 3.12 全量运行 **816 项，814 项通过、
2 项因本机缺少 FFmpeg 跳过**。新增回归在修复前复现错误，在修复后通过，覆盖 Meari/NVR、
其他 SDK、缺失及无效元数据、离线设备和元数据刷新。发布 CI 安装 FFmpeg 并执行全量测试、
HACS validation 和 hassfest。

本版按普通 GitHub Release / Latest 发布，`Pre-release=false`；下一次临时版本为 `2.0.0b2`。
