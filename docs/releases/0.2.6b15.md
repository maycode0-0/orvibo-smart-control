# v0.2.6b15

修复两个 ORVIBO Lovelace 自定义卡片同时显示 `Custom element doesn't exist` 的问题。

- **资源注册时序**：集成配置条目加载或重载时再次注册门锁卡片和录像回放卡片的 JavaScript 模块，覆盖 Home Assistant 已启动后添加集成，以及 Lovelace 资源仍在恢复的场景。
- **用户影响**：更新后无需删除卡片配置。重启 Home Assistant 并强制刷新浏览器后，两个卡片应能正常识别。

Node.js 卡片语法检查通过，NVR 与门锁卡片回归测试 **9 项通过**。完整 Python 测试、HACS validation
和 hassfest 由发布流水线执行；真实 Home Assistant 实例仍需用户更新后确认。

本版按普通 Release / Latest 发布，bN 用于区分临时诊断版本，不标记为 Pre-release。
