# 2.0.0b12 MixPad 场景播报确认

本临时诊断版同步 MixPad 场景播报确认补丁：检查 `cmd=195` 的整体响应及可选动作结果，更新后立即读回云端场景并校验文字、目标和动作，再执行保存的场景。

服务结果包含请求编号、脱敏 ACK 摘要及分阶段耗时。`cloud_text_verified` 仅表示云端配置一致；`panel_sound_verified=false` 不代表实际听音验证。未进行真机验证，既有协议档案的 `hardware_verified` 不变。

验证：Python 3.12 下 75 个 speech/SSL 回归测试通过。全量 970 项测试有 5 个视频失败，其中 2 个需要更新 FFmpeg，另 3 个进程时序用例在基线和本检出版本均通过；无硬件测试。

在内置市场或 HACS 更新到 **v2.0.0b12** 后，重启 Home Assistant。

本版为普通 GitHub Release / Latest，`Pre-release=false`；下一次临时版本为 `2.0.0b13`。
